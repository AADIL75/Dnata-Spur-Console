Scanner Log In / Log Out is intentionally not a button here. It must be done by physically scanning the QR code stuck to each scanner (400, 401, 402) when you pick it up and again when you return it. That physical scan is what proves the scanner is actually in your hand — not left inside a ULD or container. A console button could be tapped without ever touching the scanner, which would defeat the safety check, so this step stays exactly as it is today.
